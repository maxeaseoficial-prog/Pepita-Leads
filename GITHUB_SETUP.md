# GitHub — Pepita Leads

Repositório de destino:

https://github.com/maxeaseoficial-prog/Pepita-Leads.git

O projeto já está inicializado localmente em Git, branch `main`, e o `origin` já aponta para esse repositório.

## Para enviar em uma máquina com acesso ao GitHub

```bash
git push -u origin main
```

Se a máquina ainda não estiver autenticada:

```bash
gh auth login
git push -u origin main
```

ou use a autenticação normal do Git Credential Manager / navegador.
